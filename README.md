# Практические работы по Java

В этом репозитории собраны три практические работы, выполненные в рамках учебного курса по Java. В каждой работе разбирались разные темы: от основ ООП и работы с коллекциями до тестирования кода и взаимодействия с внешними API.

## Практические работы

### Практическая работа № 1 — «Арена героев»

*Файл:* Adil1java.7z

В этой работе нужно было разработать консольную игру на Java, в которой герой может покупать предметы, выбирать противников и проходить испытания. Также реализуется система характеристик героя и история боёв.

Что изучалось:
- Создание классов и объектов, инкапсуляция.
- Работа с коллекциями List и ArrayList.
- Поиск, фильтрация и сортировка данных.
- Работа с инвентарём и покупкой предметов.
- Расчёт силы героя и противников.
- Обработка результатов боёв и ведение статистики.

### Практическая работа № 2 — «Тестирование и рефакторинг объектной модели»

*Файл:* Adil2java.7z

В этой работе рассматривалась система проката оборудования. Основная задача заключалась в том, чтобы найти и исправить ошибки, проверить работу программы с помощью тестов и сделать структуру кода более удобной для дальнейшего развития.

Что изучалось:
- Написание тестов с помощью JUnit 5.
- Проверка правильных и ошибочных операций.
- Исправление ошибок в логике выдачи и возврата оборудования.
- Разделение обязанностей между классами.
- Использование принципа единственной ответственности (SRP).
- Реализация разных тарифов с помощью RentalFeePolicy.
- Запись информации об успешном возврате оборудования.

### Практическая работа № 3 — «Личный каталог Pokémon»

*Файл:* Adilbek3practicPokemon.7z

В этой работе нужно было создать консольное приложение для работы с данными Pokémon. Программа использует PokéAPI, позволяет искать покемонов, фильтровать их по типам и собирать собственную команду.

Что изучалось:
- Использование record для создания моделей данных.
- Работа с HTTP-запросами и JSON.
- Получение и проверка данных из внешнего API.
- Поиск и фильтрация Pokémon.
- Создание команды из разных покемонов.
- Расчёт средних характеристик команды.
- Сохранение данных в файлы, кэширование и работа без интернета.

## Используемые технологии

- Java
- Maven / Maven Wrapper
- JUnit 5
- HTTP и JSON
- PokéAPI
- SLF4J / Logback
