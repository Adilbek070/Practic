Практические работы по Java

Репозиторий содержит три практические работы, выполненные в рамках учебного курса по Java. Работы охватывают объектно-ориентированное программирование, коллекции, модульное тестирование, рефакторинг и взаимодействие с внешним API.

Содержание

Практическая работа № 1 — «Арена героев»

Файл: Adil1java.7z

Разработка консольного приложения на Java с объектной моделью героя, предметов, противников и результатов боёв.

Основные темы задания:

* классы, объекты и инкапсуляция;
* коллекции List и ArrayList;
* добавление, удаление, поиск, фильтрация и сортировка элементов;
* инвентарь и покупка/продажа предметов;
* расчёт силы, допуск к испытаниям и обработка результатов боёв;
* история боёв и игровая статистика.

Практическая работа № 2 — «Тестирование и рефакторинг объектной модели»

Файл: Adil2java.7z

Работа с моделью проката оборудования: проверка правил выдачи и возврата, исправление ошибок и улучшение структуры кода.

Основные темы задания:

* модульное тестирование с JUnit 5;
* проверка корректных и ошибочных сценариев;
* сохранение состояния при отказе операции;
* принцип единственной ответственности (SRP);
* выделение каталога оборудования и сервиса проката;
* стратегия расчёта стоимости через RentalFeePolicy;
* стандартный и долгосрочный тарифы;
* журналирование успешного возврата с SLF4J.

Практическая работа № 3 — «Личный каталог Pokémon»

Файл: Adilbek3practicPokemon.7z

Разработка консольного каталога Pokémon на основе данных PokéAPI с возможностью поиска, фильтрации, формирования команды и сохранения результатов.

Основные темы задания:

* Java record и проверка входных данных;
* получение данных через HTTP и работа с JSON;
* преобразование ответов API в собственную модель данных;
* поиск Pokémon по имени и фильтрация по типу;
* формирование команды до шести разных Pokémon;
* расчёт средних характеристик команды;
* кэширование, офлайн-чтение, сохранение состояния и экспорт подборок.

Технологии и инструменты

* Java
* Maven / Maven Wrapper
* JUnit 5 (практическая работа № 2)
* HTTP и JSON (практическая работа № 3)
* PokéAPI (практическая работа № 3)
* SLF4J / Logback (практическая работа № 2)
